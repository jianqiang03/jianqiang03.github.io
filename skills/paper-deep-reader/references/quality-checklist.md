# 论文解读质量清单

先检查阻断项，再检查表达质量。默认目标是生成一份零背景可进入、博士层级可复核、图文交错的完整文章式解读。

## 1. 来源与事实：阻断项

- [ ] 标题、作者、版本、年份、页码和图表编号没有混用。
- [ ] 核心机制、数字、公式、图表和结论均有可定位的一手来源。
- [ ] 作者主张、直接证据、本文推断和外部背景被区分。
- [ ] 来源缺失、冲突、解析失败或版本差异已明确标注。
- [ ] 没有把二手解读或模型记忆当成论文证据。
- [ ] 没有伪造页码、引用、数字、公式、实验或视觉观察。

## 2. 零背景可理解性：阻断项

- [ ] 报告从具体问题或场景开始，没有用一串方法名开场。
- [ ] 每个影响主线理解的术语、缩写和指标在首次出现时用白话解释。
- [ ] 术语说明包含“是什么”和“在本文中做什么”，需要时补精确定义、单位、范围或区别。
- [ ] 没有用另一个未解释术语定义术语，没有循环定义或孤立缩写。
- [ ] 类比之后回到了论文的精确定义，并说明类比失效处。
- [ ] 至少一个最小例子从输入走到输出，而不是只给一个表面比喻。
- [ ] 每个关键步骤都说明拿到什么、做什么、改变什么、为什么必要。
- [ ] 常见误解或过度外推被主动指出。

执行“零背景抽查”：随机选择一名不懂该领域的读者视角，读到任一关键术语时，前文是否已经给出足够信息？若仍需外部搜索才能继续，视为未通过。

- [ ] 每个承重问题后有作者的具体处理；未处理或未披露的部分明确指出，补充建议不冒充论文方法。
- [ ] 训练条件/标签与推理来源、设置及刷新方式相连；参数具有分母、作用位置与单位。
- [ ] 正文是连续讲解，不是把内部事实核查字段逐项展示；读者能复述样本如何被处理。

## 3. 文章结构与技术深度：阻断项

- [ ] 导语明确问题、核心操作和阅读主线；默认四章加总结，章节名称贴合具体论文。
- [ ] 模型定位、核心机制、训练与使用、实验支持形成连续解释，必要的背景与贡献融入其中。
- [ ] 作者方案紧跟所提出的问题，样本链没有被固定栏目切碎。
- [ ] 用户明确指定其他组织方式时遵循用户要求。
- [ ] 技术深度达到用户目标：不能只复述摘要、图注、贡献列表和结果数字。

## 4. 方法、公式与创新：阻断项

- [ ] 能说出完整链条：问题 → 缺口 → 洞见 → 机制/论证 → 证据 → 边界。
- [ ] 方法流程包含输入、中间状态、输出、模块连接和成功标准。
- [ ] 对最接近旧方法写清改动及代价；使用自然叙述，不强制 Before / After 等正文标签。
- [ ] 每个承重公式/定义先讲目标，再解释全部必要符号与操作直觉。
- [ ] 关键公式有最小数值、逻辑或边界例子，并映射回方法步骤。
- [ ] 假设、近似、维度、适用范围和实现跳步被说明。
- [ ] 没有因论文公式多而全部搬运，也没有因追求易懂而删掉承重数学。
- [ ] 创新被压缩到最小新颖单元，没有把“首次/SOTA”直接当成事实。

### 模型训练与系统解读的附加阻断项

- [ ] 一个具体样本贯穿预处理、关键张量/掩码、目标/损失、梯度及推理；缺失接口明确标为未公开。
- [ ] 核心方法解释了信息、监督或优化怎样改变，以及成立假设、失败条件和可区分证据。
- [ ] 损失的目标、归约维度、有效元素分母与可训练参数已核对；未把缓存、包装或模块名称当作梯度证据。
- [ ] 官方代码固定版本、函数与调用配置可定位；预训练、微调、推理和模型变体未混用。
- [ ] 报告事实、代码事实、教学简化/推断与未披露项可区分；不存在用推导补造作者公式或实验的情况。
- [ ] 推理输出与外部执行接口已区分；速度与资源数字附必要条件，未把工程加速等同于学习质量提升。
- [ ] 未执行的建议实验明确标注；格式校验通过没有被当成技术正确性验证。

## 5. 图表与图文邻接：阻断项

### 两种模式共同检查

- [ ] 所有编号视觉对象已进入 manifest，并分类 `key: true|false`；每项都有具体 `classification_reason`，不能靠批量标非关键规避覆盖。
- [ ] `explain` 中所有 `key: true` 对象均设置 `selected_for_report: true`；没有 2–4 张的任意数量限制。
- [ ] 每个关键对象填写 `report_role` 和具体的 `selection_reason`。
- [ ] 关键图表出现在首次承担论证作用的位置，不是集中贴图或只在文中写图号。
- [ ] 图前说明“回答什么问题、先看哪里、怎么读”。
- [ ] 图后解释元素/比较关系、关键观察、观察到主张的推理桥、不能推出什么。
- [ ] 需要后续证据时，说明下一项图表或实验为什么必要。
- [ ] 没有把图注翻译、逐轴朗读或图片存在本身当成详细解读。
- [ ] 表格说明行列、单位、粗体/脚注和公平比较条件；定性图检查挑样、色标、后处理与失败案例。

### 视觉模式

- [ ] 所有关键对象已直接打开核查；资产未裁掉轴、图例、单位、列名、脚注或相关面板。
- [ ] 每个关键对象使用经过核验的截图，图片路径、编号、alt 文本和报告引用一致。
- [ ] 自动裁图只在核验后才设置 `visual_verification: complete` 与 `crop_review_required: false`。

### 无视觉模式

- [ ] 报告声明未直接核验图片像素。
- [ ] 每个关键对象记录文字来源、可恢复内容、证据等级和不可核验范围。
- [ ] `visual_verification` 保持 `not-performed`，除非有明确外部核验记录。
- [ ] 未嵌入未经核验的候选裁图，也未声称看到颜色、曲线、面板或布局。

只有 `audit` 需要在附录显示全部非关键编号对象；默认 `explain` 在 manifest 保留全量账本即可。

## 6. 实验、证据与边界：阻断项

- [ ] 实验按问题和证据阶梯组织，不是按图表编号流水账。
- [ ] 每个关键指标解释真正测量什么、数值高低代表什么和潜在偏差。
- [ ] 数据/样本、基线、对照、资源、预训练、分辨率、后处理和比较条件被说明。
- [ ] 关键主张均有最强直接证据、支持等级和最大边界。
- [ ] 支持等级没有超过研究设计、对照、证明或材料允许的范围。
- [ ] 因果、机制、相关和预测结论没有混写。
- [ ] 百分点与相对百分比没有混淆。
- [ ] 消融、稳健性、负例和失败案例说明了隔离对象及残留替代解释。
- [ ] 明确指出最可信和最薄弱的一项结论。
- [ ] 结论没有从特定数据、架构、样本或场景外推到“普遍必然”。

## 7. 贡献、影响与未来方向：阻断项

- [ ] 贡献按问题、方法、证据/资源等真实类型总结，没有重复摘要。
- [ ] 影响区分近期研究、长期学术和实践/产业价值。
- [ ] 每个未来方向都能追溯到本文的具体局限、未验证假设或可迁移机制。
- [ ] 每个未来方向至少包含一个可检验问题和最小验证方案。
- [ ] 没有“扩大数据、提升效率、探索更多场景”等无对象、无机制、无验证方式的套话。

## 8. 完整而不账本化

- [ ] 完整性来自机制链、承重对象和关键证据全覆盖，不来自固定字段数量。
- [ ] 同一结论没有在摘要、方法、结果、贡献和结论中原样重复。
- [ ] 非关键公式、全量 Related Work、运行日志和内部清单未进入主文。
- [ ] 每段至少跨过一个知识门槛，或新增机制、证据、创新差分、影响或边界。
- [ ] 删除任何段落前已确认不会破坏零背景理解链或技术审查链。

## 9. `audit` 附加检查

- [ ] 全量图表覆盖、主张—证据审计、复现或审稿材料只包含任务需要的部分。
- [ ] 每个非关键视觉对象说明作用与略读理由。
- [ ] 承重公式、定义、定理或研究设计没有逻辑跳步。
- [ ] 复现清单区分已报告事实、合理推断和缺失信息。
- [ ] 附录没有重复主文，而是提供可核查细节。

## 10. 文件与最终红队

- [ ] 没有 `TODO`、`TBD`、未替换占位符或空小节。
- [ ] 本地图片和文本证据路径存在，Markdown 标题、公式和表格可渲染。
- [ ] `source_map.json`、manifest、报告模式和实际视觉能力一致。
- [ ] 文章使用 validate_article_assets.py 检查资产与来源；写作质量、事实和图像核验另行人工检查。旧六部分校验仅用于旧结构。

最后回答：

1. 完全不懂该领域的人能否不查外部资料复述问题与方法？
2. 专家能否指出方法相对旧工作的最小差分和关键假设？
3. 每张关键图是否真正推进了一步论证，而非只是装饰？
4. 哪个结论最容易被夸大，哪项证据仍排除不了替代解释？
5. 未来方向是否能转化为一个实际可做的最小实验？
6. 是否有一段只在展示工作量，没有帮助理解或判断？

任一答案暴露问题时，先修复对应段落，再运行校验。


## 11. 主线重建检查

- [ ] 读者在开头已知道最核心的改动，篇幅集中于决定效果的方法与证据。
- [ ] 数据、公式、训练、推理和附录参数在对应机制处连贯出现，而非互不相干的清单。
- [ ] 条件化、损失加权、冻结和梯度隔离按实际实现区分；没有把可能的机制当作已证实因果。
- [ ] 技术缺口可见，迁移建议有归属；没有整段照搬或逐段换词改写参考文章。

- [ ] 原图按论证对象独立裁切，裁切未损失图例/坐标/脚注；窄图没有被不必要拉宽。
- [ ] 图文穿插与正文节奏参考已确认的文章式样例，未复制第三方正文或图片。
